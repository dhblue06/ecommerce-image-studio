# 单图制作：白底与透明

## 准确性与构图

1. **真实商品优先于美观。** 保留实际型号、色彩、数量、结构、接口、按键、配件、材质及原有品牌。产品本身的标识不等于新增水印。不得编造规格、认证、条码、细字或遮挡结构。
2. **完整主体最长边目标约 85%，必须验收成图，不能只写进提示词。** 主体包括全部线缆、接头、挂绳、表带、天线、支架；包装包括整个挂卡与提手。阴影不计入。比例采用完整主体外接框最长边/方形画布边长，是本地测量约定，不能冒称平台的通用面积公式。
3. Google/独立站（含PrestaShop）白底图目标约 85%，本地验收参考 75%–90%；Amazon 主图目标约 88%，本地参考 85%–90%，为至少 85% 留余量。保持真实比例、完整入镜与安全留白，不裁线缆来凑数。细长商品另一方向空白多正常。特殊品类按核实规则调整，不把这套白底构图强套服饰模特图或细节裁切图。
4. 默认白底图：1:1、不透明 #FFFFFF 背景、摄影棚柔光、真实材质、轻微中性接触阴影；无灰底渐变、外围光晕、重影、色边、道具和新增叠字。Amazon 主图背景按纯白检查；不通过时标待修，不用“看起来白”代替文件核验。

以上占比只约束完整产品/包装白底图；不套到 Pinterest 2:3、社交 4:5/9:16、信息图或 A+ 模块。对竖版位置先保护主体、文案与 UI 安全区，不为占比裁产品；适配应重新排版或有依据地扩展背景，不直接把方图拉长。没有经核实的 UI 模板时使用保守中央布局，并标安全区待平台预览。


## 编号4：两张独立输出的执行约定

先建立当前款式的两条输出记录，再分别调用生图工具；每次调用只请求一张、一个角色。不要把“产品＋包装”直接作为生成器的画面描述。

- product-only：只保留一个所选款式的独立产品及其真实自带部件；不出现包装盒、包装平面、宣传图标或额外产品角度。仅有包装照片时，以中央最完整的产品插图重建；不能把侧视插图一起变成多件商品。输出标记为包装插图重建。
- package-only：只保留该款完整包装，包装内原本印刷的产品图片照常保留；包装外不摆放独立产品，不删除包装印刷产品图。
- 两条记录共用同一型号/颜色证据和商品档案版本；颜色从实物及包装主产品插图核对，不根据SKU后缀、旧对话或其他生成图猜测。源图冲突则补问，不能擅自“纠正”成其他颜色。
- 每次工具调用只绑定本款所需的真实参考图。不要让默认“最近图片”带入其他款式、截图里的示例商品或先前生成结果；支持显式文件引用时优先使用。无法隔离参考时明确指定每张参考用途，并在输出后重点比对身份。
- 产品提示补充：“本次只生成独立产品，不出现任何包装盒或拼图。”包装提示补充：“本次只生成完整包装，保留盒面印刷，盒外不出现独立产品。”两次都写明具体颜色与不可改变结构，不使用互相冲突的角色要求。

## 制作方式

- **编号5：产品透明背景图。** 将用户提供或本任务已确认的产品白底图背景移除，保持产品原款、颜色、结构、文字、视角和清晰度，不改成新设计。不要求先额外生成白底图；已有合适图直接编辑。保留完整线缆、接头、挂绳等最外端，移除白底、背景光晕、地面阴影和反射，孔洞与部件间空隙也应透明。产品自身的白色、银色、高光及半透明材质不能被误删。未指定时保持原尺寸与构图，用户另要求方图/占比再适配，不因通用白底规则强制重构图。
- 透明图必须导出PNG并有真实alpha：明确背景像素alpha=0，实体内部应保留正常不透明度，边缘可抗锯齿，透明材质按实际保留。禁止用白色、黑色或棋盘格图案冒充透明。使用图像工具时启用真实透明背景参数（若有），不是仅在提示词写“透明”。用`transparent-product`配置预检，并在白/灰/深色预览上检查白边、黑边和残留；预览不替代透明原文件。仅检查alpha极值不能证明抠图干净，孔洞与边缘仍需目视。透明PNG属于设计素材，不自动标为Amazon纯白主图；另要白底上传图时单独输出，不能改掉透明原件。

- 清晰实物图：优先使用环境实际提供且获准的修图方式保留原始细节。受工具指令要求时使用指定图像编辑工具；不能以本 skill 绕过工具限制。只有用户允许且环境支持时才用确定性抠图/合成。不要把能保留的商品细节无故重画。
- 只有包装：包装图保留完整盒体和印刷产品图，去除手与环境；参考充分时展示轻微立体厚度，不臆造侧面印刷。Amazon 通常将包装列为附图，不默认设 MAIN。
- 用户明确要求从包装提取产品：以最完整印刷主视图重建，只保留产品自身的印刷内容；去除包装底色、外部参数、图标、指示线，不把包装插图的多个角度生成为多个实物。标为“包装插图重建、待实物核对”，不能直接宣称可作 Amazon 合格主图。
- Google Business 商家资料照片：优先真实实物/店面照片的克制调整，不生成虚构门店、货架、人物或营业环境，不把包装重建作为已核实真实商家照片。TikTok Shop 与 AliExpress 也须按所在站点检查实拍/渲染限制；未确认前不把合成重建判为销售主图就绪。
- 细节/场景图：仅在请求范围内制作；场景尺度、连接方式和配件须真实，不发明使用性能。文字信息图只在用户需要且对应附图位置允许时做，内容须有依据；保留无叠字版本供商品 feed 使用。
- 一张独立输出对应一个销售款式/套装及一个图片角色，不用拼图替代多个文件。视角选择以真实参考为准，不强制所有产品三分之四转角。


## 白底提示词

按任务填入具体不变量和平台差异，不把整份 skill 原样塞进生成器。

> 依据【源图】只制作【目标款式/产品或包装/输出角色】。忠实保留【关键外形、结构、颜色、品牌及印刷】，移除【手、环境及非销售内容】，不编造细节。采用【有参考依据的视角】。1:1 白底摄影棚柔光，真实材质和轻微自然落影。完整主体包括【最外端部件】，最长边目标约【85%/Amazon主图88%】，安全留白、完整入镜、不拉伸。无新增广告、水印、边框或额外款式。优先原生2048×2048，【格式】。

包装提取、场景或细节图按上节追加短约束；不要在单次提示中同时要求“只产品”和“只包装”。尺寸同时使用工具可用的尺寸设置；写入提示词不代表实际已输出该尺寸。模型能力不足时说明，不承诺所有模型同等保真。
