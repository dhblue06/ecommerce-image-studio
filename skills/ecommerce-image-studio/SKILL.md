# 电商图片工作室

只做商品图的事实整理、卖点视觉策划、图内文案、图片制作与验收；不写listing、不操作库存、不上传或同步网站，也不调用旧上架skill。工具遵循当前环境授权，不绑定模型或第三方中转站。

## 1. 先判断任务，只问必要问题

只发图或意图不清时先读 [快速询问](references/intake.md)，等待选择：1产品白底、2包装白底、3卖点套图、4产品与包装各一张独立白底、5产品透明背景。已明确则不重复问。套图缺平台且上下文无法确定时问一次；其余默认或按已给要求执行，不反复确认开始。

编号4是交付组合，不是合照：每款固定输出两张独立文件（product-only、package-only），分两次单主体生图，禁止同画面摆放产品与包装。只有包装源图时，编号4已包含从包装主插图重建独立产品的请求；证据不足则标待核对，不换款补齐。

单图只做所选主体；白底未指定平台按独立站默认。套图默认最多规划6个有价值且有证据的画面，社交轮播默认4张，用户指定数量优先；画面角色由品类与证据决定，不强行凑六种固定角色。

## 2. 锁定商品事实（所有模式共用）

查看参考图，先按 [商品事实档案](references/product-facts.md) 建立或复用每款 `product-facts.json`，可复制 [模板](assets/product-facts.template.json)。单张也可精简填写，不为白底图做营销问卷。不同颜色/型号独立档案；保留来源、状态、冲突和unknown，不能拿旧生成图当真实规格。

每张提示必须包含从当前档案导出的identity lock：形状/比例、颜色、材质、Logo位置、结构与接口、销售数量/配件及禁改项。包装标称不冒充实测。风格锁只管光线、色板、字体系，不能覆盖商品事实。

## 3. 按需读取，避免全量加载

| 当前任务 | 本次读取 |
|---|---|
| 产品/包装白底、透明图 | [单图模式](references/image-modes.md)；透明图不强套白底尺寸、占比或阴影 |
| 卖点套图/信息图/场景 | [卖点工作流](references/selling-point-workflow.md) → [品类选图](references/category-playbooks.md)对应一行 → [图型配方](references/shot-recipes.md)所需段落 |
| 指定平台/社交位置 | [欧洲渠道](references/europe-channels.md)对应位置，必要时 [基础平台规范](references/platform-rules.md)对应段落；不要每张重查 |
| 生成后的执行与验收 | [验收交付](references/quality-delivery.md)；只读脚本 `scripts/preflight.py` |

`references/export-profiles.json` 是制作/预检配置，含本地目标，不能把全部字段当官方要求。正式提交、要求最新规范或特殊站点品类时查对应官方页面；访问受限如实标待核验。

## 4. 根据卖点生成，不能只换背景

先事实 → 有依据的利益 → 买家问题 → 可见证据，再规划每个slot的构图、文案、布局和验收条件。用 [套图模板](assets/shot-plan.template.json) 记录档案版本、claim引用及实际输出。品类配方只决定问题优先级，不赋予商品新参数；缺证据则换有价值图型或列缺项。

简短展示计划后按授权直接生成。各图共用商品档案与风格锁，分别生成独立文件。主图/目录保留无叠字版；附图/社交文字按允许位置制作。需图内文字且未指定语言时按会话偏好，否则默认es-ES并说明。文案必须来自档案，不编造认证、性能、评价、价格或折扣。

## 5. 公共硬规则与结束标准

- 商品准确、完整优先。白底完整主体最长边目标85%（本地75%–90%），Amazon主图目标88%（本地85%–90%）；包括线缆、挂绳、表带或包装挂卡，阴影不计。这是本地检查口径，不冒称平台面积公式。不裁切、不拉伸；细节/社交版不机械套此占比。
- 白底图默认1:1、#FFFFFF不透明、柔光与轻微自然落影、2048目标；透明图是真alpha PNG、清除背景/地影并保留产品白色与孔洞，默认保留原尺寸构图。读取实际尺寸，提示词不能保证分辨率、文字或保真。
- 从包装插图重建必须标记并待实物核对；Google Business优先真实照片，其他平台的实拍/渲染限制按相应规则处理。未确认事实不得进入确定性文案。
- 复用合格图，独立图在工具允许时约2张并发；同一问题最多额外修正2次，不无限重画。变更事实后仅复查/重做依赖该事实的图片，不盲目沿用旧图。
- 实际文件、视觉检查和只读预检都要完成；占比/纯白无可靠框或mask时写unknown或目视估计。保留来源元数据，平台就绪与文件检查分开，不能承诺审核通过。
- 默认保存 `output/ecommerce-image-studio/<批次>/`，按SKU/颜色/角色命名，不覆盖源图；交付实际数量、实际尺寸、报告、套图预览及缺项。只有提示词/策划或缺文字成图不算完整完成。
