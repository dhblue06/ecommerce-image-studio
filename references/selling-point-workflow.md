# 卖点驱动的电商图片制作

目的：一套图形成购买信息的递进，而非同一产品在不同背景上的重复摆拍。只做用户要求的图片，不扩展成listing或全渠道营销。

## 1. 卖点证据表

先建立/核对product-facts.json。每个卖点记录claim_id、fact_ids、buyer_benefit、conditions、visual_proof、forbidden_inferences；证据来源与状态从档案继承，不在每图复制另一份相互矛盾的规格。

证据状态：
- visible：从实物直接看见的结构/接口/显示内容，不能推出不可见内部材质或性能。
- supplied：用户明确提供的规格；存在冲突先核对，不能选择更好卖的数值。
- packaging_claim：包装标注的容量/功率/认证等，是标称信息，非实测证明；需要时写“标称”，保留兼容条件。
- unknown：看不清、未提供或互相冲突；不用作确定事实、图内参数或比例图。

判断优先级：与购买决定相关、证据足够、容易被画面解释的卖点优先。不要按包装文字顺序机械排图；不要为了六张图硬拆一个弱卖点。可合理表达使用便利，但不发明节省时间/充电次数/覆盖面积/防水等级/寿命/性能对比。

## 2. 从参数到画面

每张采用链条：事实 → 用户收益 → 用户疑问 → 能展示的证据 → 画面与短文案。

| 事实示例（必须有源证据） | 可表达利益 | 画面表达 | 不能推断 |
|---|---|---|---|
| 自带USB-C/Lightning线 | 少带一根对应充电线 | 接口与线的真实细节、已确认兼容设备连接 | 所有手机通用、双设备同时快充 |
| 标称22.5W输出 | 支持所标称快充能力 | 接口特写+“Hasta 22,5 W”及确有依据的适用条件 | 固定几分钟充满、所有口同功率 |
| 数字电量显示 | 便于查看剩余电量 | 屏幕特写+短利益标题 | 显示值就是实时精确电芯容量 |
| 已确认尺寸 | 判断空间/携带适配 | 正确端点的尺寸线、公制数值 | 凭图猜尺寸、随意缩小产品放进口袋 |
| 标注HDMI 4K60支持 | 对应条件下的画面传输 | 真实端口、设备连接示意，说明支持规格 | 修复网络卡顿、提高游戏原生帧率 |

以上只是方法示例，不自动赋予任何实际商品这些卖点。

## 3. 根据品类安排阅读顺序

先读category-playbooks.md对应品类。下面是可选择的角色，不是每套固定六张的强制顺序；按买家疑问和证据重排、合并或替换。

1. 商品识别：实际售卖款式/数量，干净主图；回答“买到什么”。主图不叠字。
2. 核心价值：最重要且有证据的利益；用一个视觉重点和一句标题，而非参数墙。
3. 功能证据：接口、结构、材质或屏幕特写；回答“凭什么这么说”。
4. 使用情境：真实用户任务、尺度与连接；回答“我怎么用”。不虚构性能结果。
5. 适用性：已确认的尺寸、接口、兼容条件或使用边界；回答“适不适合我”。无尺寸证据可改为真实操作步骤，不假画背面/按键功能。
6. 交付与细节：已确认的包装/配件/套装清单或重要维护说明；回答“具体包含什么”。没有配件清单就不猜，替换为另一关键事实。

未指定数量最多默认规划6张有价值画面，不为凑六张强加尺寸/配件图。用户只要3张时按品类选主图+最强卖点证据+适用信息；指定7张时增加另一个独立买家问题，不重复同一画面。推荐数量不等于平台政策。对只适合真实照片的渠道，如Google Business，选择真实实拍内容，不能用生成场景替代真实商家照片。

## 4. 每张图必须具体到可生成

slot记录：
- buyer_question：用户疑问；claim_ids/fact_ids：引用当前商品档案支持的卖点与事实，记录档案revision。
- visual_proof：靠哪些真实部件/细节说明，不能只写“高级感、科技感”。
- composition：主体位置、大小、视角、必要道具、背景；禁止新增物品误认同售。
- copy：headline、support、qualifier、language；主图/目录禁叠字位置全部为空。
- layout：字区、商品区、留白、顺序、安全区和移动端字号检查；不同角色用不同构图。
- acceptance：这张图怎样才算讲清楚对应卖点，哪些结构/文字须与源图一致。

将身份锁、风格锁和上述slot规则组成单张prompt；不能一次要求模型把六张都画进一幅拼图。产品实物图、包装印刷产品图、重建图来源分别标记。

## 5. 图内文案与排版

用户要套图即允许起草必要短文案，遵循指定语言，未指定默认es-ES并说明。通常标题3–7个词，辅助句不超过约15个词；这是本地可读性建议，不是平台限制。一个画面一个主要信息，关键限定不能因缩小字或截断被隐藏。术语、数字和小数写法符合目标语言。

能用真实细节说明就不用抽象装饰符号。图标仅作辅助，不生成似官方认证的徽章。图中大字不得挡接口、标签或关键配件。密集参数表、字体错字、单位和尺寸线端点须逐项核对；可用环境允许的图像/排版工具分步制作，但不得绕过工具限制。

有文案成图之外保留对应clean底图，便于Google/Meta目录等位置复用。只要有字的成图就必须逐字检查；工具不能准确呈现时交付无字底图和文字布局稿，明确“文字版未完成”，不伪称整套完成。

## 6. 套图级验收

- 每张有清楚的买家问题与证据，整套没有用不同背景重复同一卖点。
- 所有claim均能回到参考/用户规格，缺失字段为unknown/null，包装标称不冒充实测。
- 型号、颜色、Logo、接口、配件、比例、光线和字体系跨图一致。
- 主图/目录清洁版与附图/社交文案版分开，不把营销卡作为Amazon MAIN。
- 手机缩略预览仍识别产品与重点，安全区不挡内容；不能只检查大尺寸原图。
- 每张真实文件及clean底图路径、实际尺寸、QA状态和未完成项写回计划；只有prompt或缺字版不能计作已完成成图。
