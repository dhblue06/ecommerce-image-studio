# 按品类选择买家问题与画面

仅看当前品类对应行。不是预写规格库，不是平台合规替代。先由商品档案选出有证据的重要事实，再决定图型与顺序；缺证据换题或减量。六张是默认规划上限，不是强制六种内容。

| 品类 | 优先回答的买家问题 | 可选画面（按证据选） | 常见错误 |
|---|---|---|---|
| 电子/数码/线材/电源 | 接什么设备、如何连接、支持什么条件、随附什么 | 接口特写、实际连接步骤、明确的功率/协议条件、显示屏、已确认尺寸、包含物 | 凭接头外形推协议；乱接输入输出；线缆不完整；功率等于充满时间 |
| 服饰/鞋包 | 版型/穿着/收纳、材质纹理、实际尺寸与颜色 | 有依据的正侧背、穿着或使用、面料缝线、尺码表、包袋内部与开口 | 凭正面编背面；造面料成分；捏造尺码；误把模特效果当人人一致 |
| 家居/家具/收纳 | 能否放下、空间适配、如何使用/安装、包含哪些 | 实测尺寸线、真实比例场景、可见内部空间、组装步骤、表面与接合细节 | 随意缩小家具；编承重；虚构隐藏抽屉/安装件 |
| 厨房/餐具/小家电 | 如何操作、适用器具/食材、清洁和配件 | 已确认操作步骤、容量/尺寸、按钮结构、可拆部件、真实台面场景 | 编耐温/食品接触认证；凭外观推洗碗机可用；虚构烹饪结果 |
| 美妆/个护 | 质地、使用方法、包装容量、成分信息与适用条件 | 原标签、真实有据质地、操作、标称容量、包装清单 | 捏造临床/医疗效果、修图前后对比、凭包装猜成分/敏感肌适用 |
| 食品/饮料 | 具体品种、净含量、配料/过敏原、食用与储存 | 真实包装/标签、已知分量、食品本体参考、明确食用场景 | 猜营养/有机认证；生成不存在的配料；食物分量与销售量不符 |
| 首饰/手表/配饰 | 佩戴尺度、颜色和表面、闭合结构、适用性 | 实测尺度、细节、扣件/表带、真实佩戴参照、包含物 | 造贵金属/宝石鉴定；夸大钻石尺寸；只凭表盘推健康功能/防水 |
| 工具/户外/运动 | 连接/操作方式、适配尺寸、携带、配件 | 接头结构、明确规格、操作步骤、真实比例场景、收纳清单 | 编载荷、防护/安全等级；虚构危险操作；配件默认通用 |
| 玩具/母婴 | 实际尺寸、部件/玩法、年龄与安全信息 | 包装可读年龄、真实部件、操作、装箱清单、证实尺度 | 造年龄范围/安全认证；未提供的零件；不当使用场景 |
| 未知/混合品类 | 买到什么、怎么用、适不适合、包含什么 | 主图+最重要真实细节+有依据使用/适配 | 强套电子产品功率图或虚构材质/尺寸 |

## 如何组成一套

1. 先主图识别实际售卖内容。按销售数量展示，不把一个商品的多视角画成多件。
2. 列出3–5个高价值买家问题，按购买重要性及证据强度排序，不用商品类别自动填事实。
3. 每题选最有说服力的表达：结构用特写，使用用步骤，适配用有依据连接或尺寸，质感用真实细节，空间用正确比例场景。不是每题都用“产品+大标题”。
4. 在证据足够时补交付/配件/包装；这些不是所有品类都需要的最后一张。包装本身重要（例如食品、化妆品）时，可提早展示，主图规则仍按平台品类核查。
5. 对明确指定张数的任务优先满足有意义的不同画面；证据不足时列出待补素材，不虚构补满。先完成无依赖槽位。

## 去重与可读性

计划每张写一句“这一张新回答什么”。如果只是换背景、换标题或重复同一参数，合并/替换。整套至少区分识别、证明和适用性（素材支持时），而非统一构图堆六个卖点。移动端标题、细节与产品都需可辨，使用画面不得让人误认道具同售。
