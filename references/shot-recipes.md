# 套图规划与提示词

只读所需配方，不默认做全部渠道。借鉴独立图型、商品一致性和批次风格一致的方法，不依赖外部仓库的专有调用或模型别名。

## 身份与风格锁

先读取当前SKU/变体的product-facts.json，身份锁只从有据档案导出；每次生成头部重复简短身份锁：真实SKU/颜色/数量、轮廓与比例、材质、品牌/标签位置、接口/按键/线缆、不可增删结构。unknown明确保留，不据猜测补成规格。风格锁另写灯光、色温、场景色板、视角和附图字体系；真实商品优先。

## 图型与默认范围

| 用户请求 | 默认计划 | 缺素材处理 |
|---|---|---|
| 单张产品/包装白底 | 1张指定主体 | 不附赠整套 |
| 未指定张数的一套 | 按category-playbooks对应品类选买家问题，默认最多规划6张有价值画面 | 角色与顺序由证据决定，不强制尺寸/配件槽；无有价值替代时减量说明 |
| 指定Amazon七张 | MAIN、关键细节、单一功能、真实使用、已确认尺寸、in-box、另一真实视角 | 无尺寸/配件证据不编；不把规划槽位称为已完成图片 |
| Shopify图库 | 清洁主图、细节、使用、包装/配件，按请求数量 | 同主题比例与色调，主图无营销字 |
| PrestaShop封面与图库 | 清洁产品封面、包装、真实细节/使用图，按请求数量；记录变体颜色与建议顺序 | 先母版后主题适配；不将生成图片等同已设网站封面，不自动生成无参考的新角度 |
| 社交轮播 | 默认4张：核心使用价值→关键卖点→真实细节/使用→适用性或包含物说明 | 没获准价格/折扣不编促销；每卡一重点，结尾CTA仅用户需要时添加 |
| 多平台适配 | 先做共享清洁母版，再做实际需要的4:5/9:16/2:3版本 | 不每平台重画同一主图；不靠拉伸或裁掉产品适配 |

以上是制作建议，不是平台要求的图片数量。A+先取得具体模块，不用七张图库规格代替A+模板。

## 模块提示词

共用开头：依据【源图与身份锁】保留真实商品，遵循【风格锁】，不改变结构/文字/数量，不发明看不见细节。

- 白底产品：只保留指定款式/套装；纯白柔光、轻微自然落影；完整最外端、目标【85%/Amazon88%】，每图一视角，无新增叠字；工具允许时选择2048方图。
- 包装：只保留实体盒及全挂卡；保留原印刷产品图、布局与文字，不把印刷图变成旁边实物；真实有据的轻微厚度，全部入镜。
- 包插图产品重建：只取最完整产品主视图，移除包装/参数指示线，保留产品自身印刷；限制未知结构。输出身份为reconstruction，必须实物核对。
- 场景：匹配真实用途的【欧洲具体环境】；实际比例、连接方式和配件正确，商品为焦点，无未经证实性能；不虚构商家实际店面或顾客证言。
- 功能/尺寸附图：一个画面说明一个有证据的特点；只用已确认数字，参数文字后期可编辑排版优先于让模型生成密集小字；留无字底图。请求卖点套图即包含必要图内短文案，无需再次询问；单张无字主图不自动加字。位置不允许叠字时用视觉说明并将文案留在计划中，不印进图片。
- Feed/Pin：按【4:5/2:3】重新构图，商品明显、留指定文案区域，短句【已批准语言及文字】，不挡关键部件；保留清洁母版。
- Story/TikTok封面：9:16独立布局，避开当前UI遮挡位置；无模板时中央安全布局并标待预览，不凭空定义官方固定像素安全区。

## 工具与质量选择

先用当前环境内置且获准的参考图编辑工具；只有用户授权外部接口、成本与数据去向时才接入。需要标签细字/局部修正时选择工具当前支持的高保真方式，不能假定某个模型名称永久可用或必然保字。没有工具只输出prompt pack并标未生成，不给推广跳转链接代替图片。

同SKU多卡共用锁与参考，不拿上一款生成图当下一款实物参考。相同问题最多两次额外修正；复杂文本按实际可用排版方式处理，不无限生图。每张完成后将真实路径、尺寸、尝试次数和QA状态写入shot-plan/报告。只有通过所需检查的文件可进入final，其余draft单列。
